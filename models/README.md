3D models
====

This directory is for the files used by 3D printers (and any laser-cutting/CNC files) to produce the vehicle's custom parts — the rear camera mast/mount, counterweight box, and other PLA-printed brackets described in the [main README](../README.md#3-mobility-and-mechanical-design).
